# Stash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-book list of saved words ("stash") that keeps the sentence and the word's position in the book, from which Anki cards can be made later and the reader can jump back to the word.

**Architecture:** The ttu fork (ebook-reader-lite) reports the tapped character's position in ttu's bookmark units and can open a book at a position without touching its bookmark (`peek`). On the Flutter side a new Isar collection `StashItem` holds the items; an `AddToStashAction` quick action writes them; card fields receive their sentence and book through an explicit `CreatorContext` so cards can be made from a stored item; two new pages list and show the items.

**Tech Stack:** Flutter / Dart 3 (`isar_community`, Riverpod, slang, fluttertoast); SvelteKit / TypeScript in `../ebook-reader-lite`.

**Spec:** `docs/superpowers/specs/2026-10-11-stash-design.md`

## Review Focus

1. **Taps near furigana or non-Japanese characters**: the stored position must still land on the screen holding the word (ttu counts only Japanese characters and skips `<rt>`). Pinned in Task 1, Step 6.
2. **Peek at the very start or past the end of a book** (`position` 0, or a stale position after the book was re-imported): the reader must open without error and still not save a bookmark. Pinned in Task 2, Step 5.
3. **Normal open after a peek**: opening the same book from the library must go back to the real bookmark, with no leftover peek state. Pinned in Task 7, Step 5.
4. **Dictionary gone at card time** (deleted dictionary, or the heading has no entries left): the item page must open, show the missing-entry note, and the card actions must still fill term, reading, sentence, cloze and context. Pinned in Task 8, Step 6.
5. **Selection mode and the back button**: back in selection mode must leave selection mode, not the page; deleting every item must show the empty state. Pinned in Task 9, Step 6.

```ts
 * All rights reserved.

import type { BookmarkManager } from '$lib/components/book-reader/types';
import { getCharacterCount } from '$lib/functions/get-character-count';
import { isHost } from '$lib/host/host-bridge';

let currentBookmarkManager: BookmarkManager | undefined;

export function setHostBookmarkManager(bookmarkManager: BookmarkManager | undefined) {
  currentBookmarkManager = bookmarkManager;
}

/**
 * Position of the character at `offset` in `node`, in bookmark units
 * (`exploredCharCount`), or -1 when no book is laid out.
 */
export function positionAt(node: Text, offset: number) {
  if (!currentBookmarkManager) {
    return -1;
  }

  const range = new Range();
  range.setStart(node, offset);
  range.collapse(true);

  const before = currentBookmarkManager.charCountAtRange(range);
  if (before < 0) {
    return -1;
  }

  return before + getCharacterCount(document.createTextNode(node.data.slice(0, offset)));
}

/**
 * The `peek` URL parameter: open the book at this position and never save
 * its bookmark during this session. Undefined outside the app.
 */
export function getPeekPosition() {
  if (!isHost()) {
    return undefined;
  }

  const raw = new URLSearchParams(window.location.search).get('peek');
  if (raw === null) {
    return undefined;
  }

  const position = Number(raw);
  return Number.isInteger(position) && position >= 0 ? position : undefined;
}
```

```dart
/// A word saved while reading a book, holding what is needed to make a card
/// from it later. A book has at most one item per word: see [stashKey].
@Collection()
class StashItem {
  /// Create a stash item.
  StashItem({
    required this.mediaSourceIdentifier,
    required this.mediaIdentifier,
    required this.term,
    required this.reading,
    required this.dictionaryName,
    required this.definitions,
    required this.sentence,
    required this.wordStart,
    required this.wordLength,
    required this.position,
    required this.dateAdded,
    this.id,
  });

  /// A unique identifier for the purposes of database storage.
  Id? id;

  /// One item per word (term and reading) per book.
  @Index(unique: true)
  String get stashKey =>
      '$mediaSourceIdentifier/$mediaIdentifier/$term/$reading';

  /// The media source of the book, e.g. the ttu reader.
  String mediaSourceIdentifier;

  /// The book, as the [MediaItem.mediaIdentifier] of its library entry.
  String mediaIdentifier;

  /// The word's dictionary form.
  String term;

  /// The reading of [term]. With it, identifies the dictionary heading.
  String reading;

  /// The dictionary of the entry the word was stashed from, or null when it
  /// was stashed from the whole heading.
  String? dictionaryName;

  /// The definitions shown when the word was stashed, as plain text. Used for
  /// display, and still there if the dictionary is removed.
  List<String> definitions;

  /// The full sentence the word was met in.
  String sentence;

  /// UTF-16 offset of the word in [sentence].
  int wordStart;

  /// UTF-16 length of the word in [sentence].
  int wordLength;

  /// Where the word is in the book, in the media source's units: characters
  /// from the start for novels.
  int position;

  /// When the word was stashed.
  DateTime dateAdded;

  /// [sentence] with the word selected, as used by the sentence and cloze
  /// fields.
  JidoujishoTextSelection getSelection() {
    return JidoujishoTextSelection(
      text: sentence,
      range: TextRange(start: wordStart, end: wordStart + wordLength),
    );
  }
}
```

```dart
  /// Save [item] to its book's stash. Returns false, saving nothing, if the
  /// book already has this word.
  bool putStashItem(StashItem item) {
    return _database.writeTxnSync(() {
      if (_database.stashItems.getByStashKeySync(item.stashKey) != null) {
        return false;
      }
      _database.stashItems.putSync(item);
      return true;
    });
  }

  /// The stash of [mediaItem], in reading order.
  List<StashItem> getStashItems(MediaItem mediaItem) {
    return _database.stashItems
        .filter()
        .mediaSourceIdentifierEqualTo(mediaItem.mediaSourceIdentifier)
        .mediaIdentifierEqualTo(mediaItem.mediaIdentifier)
        .sortByPosition()
        .findAllSync();
  }

  /// Delete the stash items with these [ids].
  void deleteStashItems(List<int> ids) {
    _database.writeTxnSync(() {
      _database.stashItems.deleteAllSync(ids);
    });
  }

  /// Delete the whole stash of [mediaItem].
  void deleteStashForMedia(MediaItem mediaItem) {
    _database.writeTxnSync(() {
      _database.stashItems
          .filter()
          .mediaSourceIdentifierEqualTo(mediaItem.mediaSourceIdentifier)
          .mediaIdentifierEqualTo(mediaItem.mediaIdentifier)
          .deleteAllSync();
    });
  }

  /// Find [item]'s word in the dictionaries for making a card. When the
  /// heading is gone, [heading] is a stand-in with no entries; when the
  /// stashed entry's dictionary is gone, [entry] is null (whole heading).
  /// [found] tells whether the stashed entry could be found.
  ({DictionaryHeading heading, DictionaryEntry? entry, bool found})
      resolveStashItem(StashItem item) {
    DictionaryHeading? heading = _database.dictionaryHeadings.getSync(
      DictionaryHeading.hash(term: item.term, reading: item.reading),
    );
    if (heading == null) {
      return (
        heading: DictionaryHeading(term: item.term, reading: item.reading),
        entry: null,
        found: false,
      );
    }

    DictionaryEntry? entry = item.dictionaryName == null
        ? null
        : heading.entries.firstWhereOrNull(
            (entry) => entry.dictionary.value?.name == item.dictionaryName);

    return (
      heading: heading,
      entry: entry,
      found: heading.entries.isNotEmpty &&
          (item.dictionaryName == null || entry != null),
    );
  }
```

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:fluttertoast/fluttertoast.dart';
import 'package:yuuna/creator.dart';

/// Saves the word to the stash of the book being read, with its sentence and
/// position, to make a card from later.
class AddToStashAction extends QuickAction {
  /// Initialise this action with the hardset parameters.
  AddToStashAction()
      : super(
          uniqueKey: key,
          label: 'Add to Stash',
          description: 'Save the word, its sentence and its place in the book'
              ' to make a card later.',
          icon: Icons.bookmark_add_outlined,
          showInSingleDictionary: true,
        );

  /// Used to identify this action and to allow a constant value for the
  /// default mappings value of [AnkiMapping].
  static const String key = 'add_to_stash';

  @override
  Future<void> executeAction({
    required BuildContext context,
    required WidgetRef ref,
    required AppModel appModel,
    required CreatorModel creatorModel,
    required DictionaryHeading heading,
    required DictionaryEntry? selectedEntry,
  }) async {
    MediaItem? mediaItem = appModel.getCurrentMediaItem();
    MediaSource? mediaSource = mediaItem?.getMediaSource(appModel: appModel);
    if (mediaItem == null ||
        mediaSource == null ||
        mediaSource.currentPosition < 0) {
      showToast(t.stash_unavailable);
      return;
    }

    JidoujishoTextSelection sentence = mediaSource.currentSentence;
    TextRange range = sentence.range;
    bool hasWord = range.isValid && range != TextRange.empty;

    bool added = appModel.putStashItem(
      StashItem(
        mediaSourceIdentifier: mediaItem.mediaSourceIdentifier,
        mediaIdentifier: mediaItem.mediaIdentifier,
        term: heading.term,
        reading: heading.reading,
        dictionaryName: selectedEntry?.dictionary.value?.name,
        definitions: getDefinitions(
          appModel: appModel,
          heading: heading,
          selectedEntry: selectedEntry,
        ),
        sentence: sentence.text,
        wordStart: hasWord ? range.start : 0,
        wordLength: hasWord ? range.end - range.start : 0,
        position: mediaSource.currentPosition,
        dateAdded: DateTime.now(),
      ),
    );

    showToast(added ? t.stash_added : t.stash_already);
  }

  /// The definitions to snapshot as plain text: [selectedEntry]'s, or those
  /// of every visible entry of [heading], in dictionary order.
  List<String> getDefinitions({
    required AppModel appModel,
    required DictionaryHeading heading,
    required DictionaryEntry? selectedEntry,
  }) {
    Map<String, Dictionary> dictionariesByName = {
      for (Dictionary dictionary in appModel.dictionaries)
        dictionary.name: dictionary,
    };

    List<DictionaryEntry> entries = selectedEntry != null
        ? [selectedEntry]
        : heading.entries
            .where((entry) => !(dictionariesByName[entry.dictionary.value!.name]
                    ?.isHidden ??
                true))
            .toList();
    entries.sort((a, b) => dictionariesByName[a.dictionary.value!.name]!.order
        .compareTo(dictionariesByName[b.dictionary.value!.name]!.order));

    List<String> definitions = [];
    for (DictionaryEntry entry in entries) {
      DictionaryFormat format =
          appModel.getDictionaryFormat(entry.dictionary.value!);
      for (String definition in entry.definitions) {
        if (format.shouldUseCustomDefinitionWidget(definition)) {
          definition = format.getCustomDefinitionText(definition);
        }
        definitions.add(definition.trim());
      }
    }

    return definitions;
  }

  /// Show a short message at the bottom of the screen.
  void showToast(String message) {
    Fluttertoast.showToast(
      msg: message,
      toastLength: Toast.LENGTH_SHORT,
      gravity: ToastGravity.BOTTOM,
    );
  }
}
```

```dart
/// Everything stored for one stashed word, with the actions to see it in the

class StashItemPage extends BasePage {

  const StashItemPage({
    required this.item,
    required this.mediaItem,
    super.key,
  });

  final StashItem item;

  /// The book the word was stashed from.

  BasePageState<StashItemPage> createState() => _StashItemPageState();

class _StashItemPageState extends BasePageState<StashItemPage> {
  StashItem get item => widget.item;

  late ({DictionaryHeading heading, DictionaryEntry? entry, bool found})

  late Future<Color?> _duplicateColour;

  InstantExportAction get _instantExport =>
      appModelNoUpdate.quickActions[InstantExportAction.key]!
          as InstantExportAction;

  CardCreatorAction get _cardCreator =>
      appModelNoUpdate.quickActions[CardCreatorAction.key]!
          as CardCreatorAction;

  CreatorContext get _creatorContext => CreatorContext(
        sentence: item.getSelection(),
        mediaItem: widget.mediaItem,

  void initState() {
    super.initState();
    _resolved = appModelNoUpdate.resolveStashItem(item);
    _duplicateColour = _instantExport.getIconColor(
      appModel: appModelNoUpdate,
      heading: _resolved.heading,
    );

  Future<void> _jump() async {
    await ReaderTtuSource.instance.peekBook(
      ref: ref,
      appModel: appModel,
      item: widget.mediaItem,
      position: item.position,
    );

    await _instantExport.exportCard(
      context: context,
      ref: ref,
      appModel: appModel,
      heading: _resolved.heading,
      selectedEntry: _resolved.entry,
      creatorContext: _creatorContext,

      context: context,
      ref: ref,
      appModel: appModel,
      creatorModel: creatorModel,
      heading: _resolved.heading,
      selectedEntry: _resolved.entry,
      creatorContext: _creatorContext,
    );
    _refreshDuplicateColour();

  void _refreshDuplicateColour() {
    if (!mounted) {
      return;
    }
    setState(() {
      _duplicateColour = _instantExport.getIconColor(
        appModel: appModel,
        heading: _resolved.heading,
      );
    });
  }

  Future<void> _delete() async {
    bool confirmed = await showDialog<bool>(
          context: context,
          builder: (context) => AlertDialog(
            content: Text(t.stash_delete_one),
            actions: [
              TextButton(
                onPressed: () => Navigator.pop(context, true),
                child: Text(
                  t.dialog_delete,
                  style: TextStyle(color: theme.colorScheme.primary),
                ),
              ),
              TextButton(
                onPressed: () => Navigator.pop(context, false),
                child: Text(t.dialog_cancel),
              ),
            ],
          ),
        ) ??
        false;
    if (!confirmed || !mounted) {
      return;
    }

    appModel.deleteStashItems([item.id!]);
    Navigator.pop(context);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(

        titleSpacing: 8,
        title: Text(item.term),
        actions: [
          IconButton(
            icon: const Icon(Icons.delete_outline),
            tooltip: t.dialog_delete,
            onPressed: _delete,
          ),

      body: SafeArea(

      children: [

        const Space.normal(),

          ),
        ),
      ],
    );

  /// The sentence with the word highlighted.

    JidoujishoTextSelection selection = item.getSelection();
    return SelectableText.rich(
      TextSpan(
        style: textTheme.bodyLarge,
        children: [
          TextSpan(text: selection.textBefore),
          TextSpan(
            text: selection.textInside,
            style: TextStyle(
              fontWeight: FontWeight.bold,
              color: theme.colorScheme.primary,

          TextSpan(text: selection.textAfter),

      ),
    );
```

```dart
import 'package:flutter/material.dart';
import 'package:yuuna/media.dart';
import 'package:yuuna/pages.dart';
import 'package:yuuna/utils.dart';

/// The words stashed while reading a book, in reading order. Long-press
/// selects items for deletion.
class StashPage extends BasePage {
  /// Create the page for [item]'s stash.
  const StashPage({
    required this.item,
    super.key,
  });

  /// The book whose stash is shown.
  final MediaItem item;

  @override
  BasePageState<StashPage> createState() => _StashPageState();
}

class _StashPageState extends BasePageState<StashPage> {
  List<StashItem> _items = [];
  final Set<int> _selected = {};

  bool get _isSelecting => _selected.isNotEmpty;

  @override
  void initState() {
    super.initState();
    _items = appModelNoUpdate.getStashItems(widget.item);
  }

  void _reload() {
    setState(() {
      _items = appModel.getStashItems(widget.item);
      _selected.removeWhere((id) => !_items.any((item) => item.id == id));
    });
  }

  void _toggle(StashItem item) {
    setState(() {
      if (!_selected.remove(item.id!)) {
        _selected.add(item.id!);
      }
    });
  }

  Future<void> _open(StashItem item) async {
    await Navigator.push(
      context,
      MaterialPageRoute(
        builder: (context) => StashItemPage(
          item: item,
          mediaItem: widget.item,
        ),
      ),
    );
    _reload();
  }

  Future<void> _deleteSelected() async {
    bool confirmed = await showDialog<bool>(
          context: context,
          builder: (context) => AlertDialog(
            content: Text(t.stash_delete_confirm(n: _selected.length)),
            actions: [
              TextButton(
                onPressed: () => Navigator.pop(context, true),
                child: Text(
                  t.dialog_delete,
                  style: TextStyle(color: theme.colorScheme.primary),
                ),
              ),
              TextButton(
                onPressed: () => Navigator.pop(context, false),
                child: Text(t.dialog_cancel),
              ),
            ],
          ),
        ) ??
        false;
    if (!confirmed) {
      return;
    }

    appModel.deleteStashItems(_selected.toList());
    _selected.clear();
    _reload();
  }

  @override
  Widget build(BuildContext context) {
    return PopScope(
      canPop: !_isSelecting,
      onPopInvokedWithResult: (bool didPop, Object? result) {
        if (!didPop) {
          setState(_selected.clear);
        }
      },
      child: Scaffold(
        appBar: _isSelecting ? buildSelectionAppBar() : buildAppBar(),
        body: SafeArea(
          child: _items.isEmpty ? buildPlaceholder() : buildList(),
        ),
      ),
    );
  }

  /// The app bar outside selection mode.
  PreferredSizeWidget buildAppBar() {
    return AppBar(
      titleSpacing: 8,
      title: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(t.stash),
          Text(
            widget.item.title,
            style: textTheme.bodySmall,
            maxLines: 1,
            overflow: TextOverflow.ellipsis,
          ),
        ],
      ),
    );
  }

  /// The app bar in selection mode.
  PreferredSizeWidget buildSelectionAppBar() {
    return AppBar(
      titleSpacing: 8,
      leading: IconButton(
        icon: const Icon(Icons.close),
        tooltip: t.dialog_cancel,
        onPressed: () => setState(_selected.clear),
      ),
      title: Text(t.stash_selected(n: _selected.length)),
      actions: [
        IconButton(
          icon: const Icon(Icons.select_all),
          tooltip: t.stash_select_all,
          onPressed: () => setState(() {
            _selected.addAll(_items.map((item) => item.id!));
          }),
        ),
        IconButton(
          icon: const Icon(Icons.delete_outline),
          tooltip: t.dialog_delete,
          onPressed: _deleteSelected,
        ),
      ],
    );
  }

  /// Shown when the book has no stashed words.
  Widget buildPlaceholder() {
    return Center(
      child: JidoujishoPlaceholderMessage(
        icon: Icons.bookmark_border,
        message: t.stash_empty,
      ),
    );
  }

  /// The stashed words.
  Widget buildList() {
    return ListView.builder(
      itemCount: _items.length,
      itemBuilder: (context, index) => buildTile(_items[index]),
    );
  }

  /// One stashed word: the term with its reading, and its meanings on one
  /// line.
  Widget buildTile(StashItem item) {
    bool isSelected = _selected.contains(item.id);
    bool showReading = item.reading.isNotEmpty && item.reading != item.term;

    return ListTile(
      selected: isSelected,
      leading: _isSelecting
          ? Icon(isSelected ? Icons.check_box : Icons.check_box_outline_blank)
          : null,
      title: Text(
        showReading ? '${item.term}【${item.reading}】' : item.term,
        maxLines: 1,
        overflow: TextOverflow.ellipsis,
      ),
      subtitle: Text(
        item.definitions.join(' • '),
        maxLines: 1,
        overflow: TextOverflow.ellipsis,
      ),
      onTap: () => _isSelecting ? _toggle(item) : _open(item),
      onLongPress: () => _toggle(item),
    );
  }
}
```
