# AGP 9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Android app on AGP 9.1.0 / Gradle 9.3.1 / KGP 2.4.0, with
APKs that are unchanged and without Flutter's version warning.

**Architecture:** This is build configuration only. It changes
`android/settings.gradle` (plugin versions and the legacy-plugin shim),
`android/app/build.gradle`, the Gradle wrapper and `android/gradle.properties`
(both opt-out flags stay `false`). No Dart code changes. A trial build decides
the fixes: each break is fixed in the shim first, and in `vendor/` only as a
last resort.

**Tech Stack:** Gradle (Groovy DSL), AGP, KGP, Flutter 3.47.7.

**Spec:** `docs/superpowers/specs/2026-11-22-agp-9-design.md`

## Global Constraints

- Versions: AGP `9.1.0`, Gradle `9.3.1`, KGP `2.4.0` (fallback: no lower
  than `2.3.20`, Flutter's warning floor, and only with the reason
  recorded).
- `android.newDsl=false` and `android.builtInKotlin=false` stay.
- Flutter stays at 3.47.7. `targetSdk` 32, compileSdk 36, minSdk 24 and NDK
  `29.0.14206865` don't change.
- APK names: `yomimoto_1.0.0-{armeabi,arm64,x86_64}.apk` (release) and
  `…-<abi>-debug.apk` (debug), with version codes `101`/`102`/`103` for
  pubspec `1.0.0+1`.
- No plugin is vendored if a Gradle-configuration fix in the shim works.
- Groovy DSL stays; don't convert to `.kts`. Don't `dart format` anything.
- Commits go through `jj` (`jj commit -m …`), ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **The per-ABI version codes silently changing**, for example Flutter's own
  `1000 * abi` scheme taking over from ours. Expect `101`/`102`/`103`.
  Pinned in Task 1, Step 6, with `aapt2 dump badging`.
- **A universal (non-split) build:** `flutter build apk --debug` without
  `--split-per-abi` should still produce `yomimoto_1.0.0-debug.apk` with
  version code `100`. Pinned in Task 1, Step 6.
- **Release-only steps** (R8 minify, `lintVitalRelease`, signing) behaving
  differently on AGP 9. These need the keystore, which isn't on this
  machine, so the user runs `tool/build_release.sh` (Task 1, Step 7).
- **Native libraries** (`libc++_shared.so` `pickFirst`, `async_zip`,
  `sqlite3`'s build hook) missing from the APK. Pinned in Task 1, Step 6 by
  listing `lib/` in each APK.
- **AnkiDroid export** (method channel and JitPack dependencies) breaking at
  runtime even though the build passes. Covered by the device check in
  Task 1, Step 7.
